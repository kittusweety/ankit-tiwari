## 📌 Overview

This is the **personal static portfolio website** of **Ankit Tiwari**, a Senior Software Developer with 2+ years of experience building scalable FinTech and enterprise-grade web applications. ## 🚀 Getting Started

### Option 1: Just Open It (Recommended)

```bash
# No installation needed!
# Simply open index.html in your browser:
start index.html        # Windows
open index.html         # macOS
xdg-open index.html    # Linux
```

### Option 2: Serve Locally (for better dev experience)

```bash
# Using Python
python -m http.server 8080

# Using Node.js (npx)
npx serve .

# Using VS Code
# Install the "Live Server" extension and click "Go Live"
```

Then visit: **http://localhost:8080**

## 🌐 Deployment

Since this is a **pure static site**, it can be deployed anywhere:

### Vercel (Recommended)
```bash
npx vercel --prod
```

### GitHub Pages
1. Push the folder to a GitHub repository
2. Go to **Settings → Pages → Source → main branch / root**
3. Live at: `https://<username>.github.io/<repo-name>`

### Netlify
```bash
# Drag and drop the /ankit folder to netlify.com/drop
# OR use CLI:
npx netlify deploy --prod --dir .
```

## 📋 Customization Guide

To personalize this portfolio for someone else:

| What to change | Where |
|---|---|
| Name, email, phone | `index.html` — Hero, About, Contact, Footer sections |
| Job titles (typewriter) | `script.js` → `dynamicTerms` array |
| Work experience | `index.html` → `#experience` section |
| Projects | `index.html` → `#projects` section |
| Skills | `index.html` → `#skills` section |
| Education | `index.html` → `#education` section |
| Color theme | `style.css` → `:root` CSS variables |
| Fonts | `index.html` → Google Fonts link + `style.css` `--font-main` |
